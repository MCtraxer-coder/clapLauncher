# 👏 Clap Launcher

Запуск приложений и сайтов по хлопкам в ладоши.

## Возможности
- Детекция хлопков через микрофон
- Авто-калибровка порога громкости
- Настройка количества хлопков, окна времени и кулдауна
- Запуск .exe / приложений или открытие URL

## Установка
```bash
pip install -r requirements.txt
python main.py
